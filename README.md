# Cart Rush: After Hours

A touch-first supermarket cart racing game built for mobile browsers and iOS
Home Screen installation. Race three laps through aisle 7, dodge obstacles,
collect groceries, and spend boost to pass the rival carts.

## Controls

- iPhone/iPad: on-screen left, right, and boost controls
- Keyboard: <kbd>←</kbd>/<kbd>→</kbd> or <kbd>A</kbd>/<kbd>D</kbd> to steer,
  <kbd>Space</kbd> to boost, and <kbd>P</kbd> to pause

## Build

```sh
npm test
```

The dependency-free build copies the required game assets into `public/` for
Netlify deployment. For local development, serve the repository root with any
static web server.
