# Cart Dash: After Hours

A mobile-first canvas racing game set in an after-hours superstore. Race a loaded shopping cart through three aisles, collect supplies for the community pantry, dodge store hazards, and beat three rival racers to the finish.

## Play locally

```sh
npm start
```

Open `http://localhost:8000`. On iPhone, the game is designed for portrait Safari and can be added to the Home Screen.

## Controls

- Tap the left and right controls, swipe, or use the arrow keys to steer.
- Hold the boost button or Space while the boost meter has charge.
- Collect yellow pantry bags, orange double bags, and blue boost pads.
- Avoid boxes, spills, and cones.

## Checks

```sh
npm test
npm run build
```

The game uses no runtime dependencies. Canvas artwork, audio cues, race logic, touch controls, and responsive UI are all implemented locally.
