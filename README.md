# Cart Dash: After Hours

A touch-first arcade racer set in a supermarket after closing. Choose a hand-built shopping cart, steer through the freezer aisle, dodge spills and boxes, collect lightning boosts, and race five rivals over three laps.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL in a landscape browser. Keyboard controls are `←` / `→` (or `A` / `D`) to steer, `Space` to boost, and `Esc` to pause. On iPhone, use the on-screen controls and add the game to the Home Screen for standalone play.

## Commands

- `npm run dev` — start the development server
- `npm run build` — create the production build in `dist`
- `npm run preview` — preview the production build
- `npm test` — run the game-logic tests

The game uses a responsive HTML canvas and procedural artwork, so no external game assets are required.
