# Cart Chaos — Web Demo

Touch-friendly HTML5 prototype of **Cart Chaos** for iPhone Safari (and desktop).

## Play

Open `index.html` in a browser, or from the repo root:

```bash
npx --yes serve cart-chaos -p 4173
```

Then visit `http://localhost:4173` (or your machine’s LAN IP on an iPhone).

## Controls

- **◀ / ▶** — steer (or tilt the phone)
- **GAS** — accelerate
- **BRK** — brake
- **ITEM** — use power-up
- Keyboard: WASD / arrows, **E** or **Shift** for item

The full native iOS SpriteKit project is in [`../CartChaos/`](../CartChaos/).
