# Cart Kart (Native iOS)

SwiftUI + SpriteKit shopping-cart racer for iPhone / iPad.

## Open in Xcode

1. Open `CartKart.xcodeproj`
2. Select an iPhone simulator (iOS 16+)
3. Set your Team under Signing & Capabilities
4. Press Run

Menus and cart select are SwiftUI; the race loop lives in `RaceScene.swift`.

For the instantly playable touch build, see `../cart-kart/`.
