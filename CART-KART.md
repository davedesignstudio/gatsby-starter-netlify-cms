# Cart Kart

Mario Kart–style **shopping cart racing** through MegaMart.

| Build | Path | How to run |
|-------|------|------------|
| **Play on iPhone (Safari / PWA)** | [`cart-kart/`](cart-kart/) | `cd cart-kart && python3 -m http.server 8080` then open on your phone |
| **Native iOS (Xcode)** | [`CartKart-iOS/`](CartKart-iOS/) | Open `CartKart.xcodeproj`, Run on simulator or device |

See [`cart-kart/README.md`](cart-kart/README.md) for controls, carts, and items.
