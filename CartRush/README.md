# Cart Rush (native iOS)

SwiftUI + SpriteKit port of **Cart Rush** — rogue shopping-cart racing in a supermarket.

## Open in Xcode

1. Create a new **iOS App** project (SwiftUI, iOS 16+).
2. Replace the default app files with the sources in `Sources/CartRush/`:
   - `CartRushApp.swift`
   - `ContentView.swift`
   - `RaceScene.swift`
3. Set the display name to **Cart Rush**, enable **landscape**, hide the status bar.
4. Build & run on an iPhone or Simulator.

### Touch controls (native)

- **Left half of screen** — drag to steer  
- **Bottom-right** — hold to accelerate  
- **Top-right** — tap to use item  

## Playable web build

For a full-featured, immediately playable build (menus, minimap, countdown, results), use the HTML5 game in [`../cart-rush`](../cart-rush).
