# Aisle Kart — Web Demo

Playable browser version of **Aisle Kart** (same rules as the iOS SpriteKit game).

## Play locally

```bash
cd aisle-kart-web
python3 -m http.server 8765
```

Open [http://localhost:8765](http://localhost:8765) — works on desktop and iPhone Safari (Add to Home Screen friendly).

## Controls

- **Touch / click** left or right side of the screen to steer
- **Arrow keys / A·D** to steer on desktop
- **Item button** or **Space** to use a power-up
- **Boost bar** or **Shift** when the meter is full
