# Aisle Kart

Mario Kart–style racing with **rogue shopping carts** tearing through a grocery store.

Abandoned carts. No owners. One finish line.

## Play now (web / iOS Safari)

Open `index.html` in a browser, or serve the folder:

```bash
npx serve aisle-kart
```

Then visit the local URL on your phone or desktop. Touch controls work on iOS.

## Controls

| Action | Desktop | Mobile |
|--------|---------|--------|
| Steer | ← → / A D | Drag left / right on track |
| Accelerate | ↑ / W / Space | Hold gas pedal |
| Brake / reverse | ↓ / S | Brake pedal |
| Use item | E / Shift | Item button |

## Features

- 3-lap supermarket aisle race
- 4 rival rogue carts with AI
- Power-ups: banana peels, soda boosts, soap slicks, canned goods
- Drift sparks, boost pads, and fluorescent store atmosphere
- Character select for different cart builds

## Native iOS (SpriteKit)

See [`../ios/AisleKart`](../ios/AisleKart) for the Xcode / SpriteKit project. Open `AisleKart.xcodeproj` in Xcode 15+ and run on a simulator or device.
