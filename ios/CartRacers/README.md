# Store Cart Racers

Store Cart Racers is a small iOS SpriteKit racing game prototype. Players race shopping carts through supermarket aisles, collect coupon boosts, dodge cereal spills, and try to finish three laps before rival carts.

## Run

1. Open `CartRacers.xcodeproj` in Xcode.
2. Select the `CartRacers` scheme.
3. Run on an iPhone simulator or device running iOS 17 or newer.

## Controls

- Drag left or right anywhere on the screen to steer.
- Two-finger tap when the coupon meter is full for a speed boost.
- Tap after the race ends to restart.

## Notes

The game uses procedural SpriteKit shapes instead of external art assets, keeping the prototype easy to build and modify.
